Finbee – Financial Tracking Application

Finbee is a basic financial tracking application developed using Python.  
The project allows users to record and manage expenses and financial data.

Features:
- User input handling
- Expense recording
- Data storage and processing
- Simple interface using Python and HTML

Technologies Used:
- Python
- HTML
- File handling

Purpose:
This project was created as part of academic learning to practice Python programming, data handling, and basic application development.
